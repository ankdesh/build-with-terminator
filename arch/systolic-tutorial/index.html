4×4 systolic array computes all 16 output elements
A systolic array is a grid of interconnected Processing Elements (PEs) that rhythmically pass data between neighbors, like a heartbeat. Each PE performs a multiply-accumulate (MAC) operation. The key design decision is which data stays stationary inside the PEs and which data streams through — this determines the dataflow strategy.

Explore the three fundamental dataflow modes below to understand the trade-offs:

Choose a Dataflow Mode

📊
Output Stationary (OS)
C stays fixed — A and B stream through
Each PE is dedicated to computing one specific element of the output matrix C. The accumulator inside each PE holds C[i][j] while elements of A stream horizontally and B streams vertically, meeting at the designated PE.
Best for: Large matrix sizes where output memory writes need to be minimized.
→
⚖️
Weight Stationary (WS)
B (weights) stay fixed — A and C stream
Elements of the weight matrix B are pre-loaded into PEs and stay fixed. Input activations A stream through the array, multiply with static weights, and partial results of C accumulate downward through the array.
Best for: Neural network inference where the same weights are reused for many inputs.
→
🔄
Input Stationary (IS)
A (inputs) stay fixed — B and C stream
Elements of the activation matrix A are kept stationary inside the PEs. Weight matrix B streams through from above, and partial products are passed rightward to accumulate the final output matrix C.
Best for: Workloads where inputs are heavily reused across multiple weight sets.
→
