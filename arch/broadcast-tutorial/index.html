C[i][j] = Σk A[i][k] × B[k][j]
4×4 broadcast PE array • 16 PEs active every cycle
Completes in exactly 4 cycles (no stagger delay!)
Unlike systolic arrays where data moves step-by-step between neighboring PEs in a staggered wavefront, broadcast-based hardware architectures use shared row and column buses to deliver data to an entire row or column of Processing Elements (PEs) simultaneously.

Explore the three fundamental dataflow modes below to understand how broadcast hardware operates:

Choose a Dataflow Mode

📊
Output Stationary (OS)
C stays fixed — A and B broadcast
Each PE holds its output accumulator C[i][j] locally. At cycle k, row buses broadcast column A[*][k] and column buses broadcast row B[k][*]. All 16 PEs compute in parallel every cycle.
Best for: Large matrix multiplications where writing partial sums to memory must be avoided.
→
⚖️
Weight Stationary (WS)
B (weights) stay fixed — A broadcasts, C reduces
Weight matrix B is pre-loaded into PEs. At cycle m, input vector A[m][:] is row-broadcast horizontally. Partial products are accumulated down each column via column reduction to output row C[m][:].
Best for: Neural network inference where the same weights are reused across many inputs.
→
🔄
Input Stationary (IS)
A (inputs) stay fixed — B broadcasts, C reduces
Activation matrix A is pre-loaded into PEs. At cycle n, weight vector B[:][n] is column-broadcast vertically. Partial products are accumulated across each row via row reduction to output column C[:][n].
Best for: Workloads where inputs are kept in local registers and reused across multiple weight matrices.
