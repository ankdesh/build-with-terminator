Before lesson one

Keep the guide beside the builder.

  1. Extract the whole tutorial ZIP. Open index.html in a desktop browser. Keep assets, data and practice folders beside the pages.
  2. Use an installed builder with its frontend assets built. Set the model endpoint and name in config.json and OPENAI_API_KEY in the environment. The downloaded tutorial pages need no API key.
  3. Start the builder from its repository root with python launcher.py, or python launcher.py --csv tutorials/data/penguins.csv. Use the URL printed in the terminal.
  4. Create a separate project for each main CSV. The CSVs are independent datasets; the application uses one CSV per project.
  5. Copy each complete prompt. Review the proposed changes and select Apply, then select Run. Use Open dashboard to reach the separate target port.
Read-only reference pages

Charts here are saved, verified results with local hover/legend/zoom interactions. They do not run your model, create projects or modify the builder. Try the actual workflow in the Studio.
