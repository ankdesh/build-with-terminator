Limits of this validation

Models can generate different code or require repair on another run. Match the data definitions and numerical checkpoints, not pixels. A real Windows executable smoke test requires a compatible archive and Windows host; neither is supplied by this tutorial pack.

Browser and release checks

All six pages, 14 charts and 13 copy controls were checked in the browser. Builder drag/resize, keyboard movement, chart binding edits, Undo/Redo and target Apply were exercised. The Python suite passed 95 tests; both frontend builds and type checks passed. Detailed QA record.

  • Direct file:// browser opening was blocked by the browser tool URL policy. The extracted files were checked on disk; direct opening remains unverified.
  • An OS-level test with external network access disconnected was not available. HTTP page checks used local assets and a policy that blocks remote scripts and network connections.
  • PNG buttons were invoked without script errors. This browser did not report the generated image downloads, so saved PNG file contents remain unconfirmed. The application export now renders a temporary canvas instead of saving SVG with a PNG name.
  • A real Windows application smoke test was not run: the compatible runtime archive and a Windows host are unavailable. Acceptance and missing-runtime export gating are covered by the service/Python checks.
