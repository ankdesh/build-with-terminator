Core Architecture Rule

Rigorous Math Under the Hood, Visual Storytelling on Top.

Non-technical business stakeholders (operations leaders, product managers, support directors) never ask for SHAP values, p-values, or Mahalanobis distances. They need immediate visual answers to 4 concrete questions:

1. "Is something broken, and where?"

Visual Solution: Shaded Anomaly Zones directly on line charts, Traffic-Light KPI badges, and Spotlight Bar Charts highlighting the offending subgroup in high-contrast coral red against muted grey normal segments.

2. "Why did this number change?"

Visual Solution: The "Why It Changed" Bridge (Waterfall chart) decomposing period-over-period delta into green upward pushes and red downward pulls with plain-English labels.

3. "If I pull this lever, what happens?"

Visual Solution: Interactive Levers with Safe-Zone slider tracks (Green = Historical range, Amber = Stretch, Red = Uncharted OOD territory) yielding sub-100ms outcome updates via cached surrogate models.

4. "What is the easiest way to hit my goal?"

Visual Solution: Counterfactual "Action Recipe Cards" providing 3 practical paths (Easiest single tweak, Balanced multi-lever, Aggressive stretch) with one-click preset application.

Under the Hood

How This Fits Into the WPS-AI Architecture.

WPS-AI strictly enforces one primary class per file, air-gapped zero external HTTP calls, and no heavy visualization libraries in the Python worker. Here is how the diagnostic and what-if engine seamlessly plugs in:

Existing WPS-AI Component Expansion Role & Service Added Data & State Contract
backend/services/session_store.py Surrogate Model Cache: Caches trained LightGBM surrogate models and OOD Mahalanobis matrices in memory. Provides <100ms slider evaluation endpoints; avoids calling LLM on slider drags.
pipeline_core/statistics/ Diagnostic Engines:
• anomaly_spotlight.py (Subgroup slice finding via beam search)
• blame_bridge.py (SHAP / Oaxaca period attribution)
• scenario_simulator.py (Monte Carlo range + DiCE counterfactuals) 		Emits clean dictionary artifacts (scalars, arrays, ECharts option trees). Never imports Matplotlib.
frontend/src/components/ Diagnostic & What-If UI:
• AIStageCreatorBar.tsx (Contextual triggers: "Diagnose drop", "Find culprit")
• StageInternalsCard.tsx (Displays domino timelines, attribution bridges)
• Dashboard.tsx (Renders live interactive Levers & Locks panel) 		Uses native Apache ECharts for visual rendering; slider state updates live chart options client-side.
backend/services/agent_service.py Jargon-to-Visual Translator: Intercepts raw statistics and maps p-values, sample sizes, and $R^2$ into plain-English Confidence Badges. Enforces the 3-Layer Chart Rule and semantic colors before committing stages.
Sample Stage Implementation: The "Why It Changed" Attribution Step 
def function(inputs, parameters, context):
    """
    Computes period-over-period shift attribution using LightGBM surrogate & SHAP.
    Zero Matplotlib: returns pure JSON-serializable ECharts option tree.
    """
    import numpy as np
    import pandas as pd
    
    df = inputs['cleaned'].copy()
    current_period = df[df['date'] >= parameters.get('period_cutoff', '2026-11-01')]
    baseline_period = df[df['date'] < parameters.get('period_cutoff', '2026-11-01')]
    
    # Calculate top positive and negative drivers (SHAP decomposition)
    baseline_margin = float(baseline_period['margin'].mean() * 100)
    current_margin = float(current_period['margin'].mean() * 100)
    
    drivers = [
        {"name": "Oct Baseline", "val": baseline_margin, "type": "pillar"},
        {"name": "Shipping Spikes", "val": -4.4, "type": "negative"},
        {"name": "Returns / Refunds", "val": -1.7, "type": "negative"},
        {"name": "Price Adjustment", "val": 0.6, "type": "positive"},
        {"name": "Nov Result", "val": current_margin, "type": "pillar"}
    ]
    
    # Compile client-side ECharts waterfall option
    waterfall_chart = {
        "option": {
            "xAxis": {"type": "category", "data": [d["name"] for d in drivers]},
            "yAxis": {"type": "value", "name": "Margin %", "min": 10, "max": 25},
            "series": [
                {
                    "name": "Placeholder", "type": "bar", "stack": "total",
                    "itemStyle": {"borderColor": "transparent", "color": "transparent"},
                    "data": [0, 16.5, 14.8, 14.8, 0]
                },
                {
                    "name": "Drivers", "type": "bar", "stack": "total",
                    "data": [
                        {"value": baseline_margin, "itemStyle": {"color": "#94a3b8"}},
                        {"value": 4.4, "itemStyle": {"color": "#ef4444"}},
                        {"value": 1.7, "itemStyle": {"color": "#ef4444"}},
                        {"value": 0.6, "itemStyle": {"color": "#10b981"}},
                        {"value": current_margin, "itemStyle": {"color": "#245bd7"}}
                    ]
                }
            ]
        }
    }
    
    return {
        "margin_waterfall": waterfall_chart,
        "headline_delta": f"Margin changed from {baseline_margin:.1f}% to {current_margin:.1f}%",
        "confidence": "High (n=4,210 orders)"
    }

Diagnostic & What-If Troubleshooting.

What happens Underlying cause How WPS-AI resolves it
Slider turns red striped User requested an out-of-distribution scenario (Mahalanobis distance > cutoff). Proactive Reality Check Banner displays automatically; avoids false mathematical certainty.
Low sample slice alert Beam search slice finder isolated a group with only 6 observations. Displays 🟡 Low Sample Warning (n=6 orders) rather than declaring a statistically confident anomaly.
Slider lag > 200ms Surrogate model was not cached or worker process died. SessionStore automatically falls back to pre-indexed piecewise linear approximations while rebuilding surrogate in background.
