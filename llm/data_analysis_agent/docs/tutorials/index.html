Before You Begin

How to use this guide with WPS-AI Studio.

  1. Keep the guide beside the builder: Open this guide in one browser tab, and open the running WPS-AI Data Analysis Studio (http://localhost:8080) in another.
  2. Start the builder: In your terminal from the repository root: 
    python launcher.py
  3. Download the dataset: In each lesson, select Download the CSV ↓ and save the file locally.
  4. Create a new project: In WPS Studio, select New project → Data → Upload CSV. Copy the provided Business Context into the text box.
  5. Copy the chat prompts: Copy the exact prompt from the guide into the Chat composer. Select Apply, then select Run ▶ to compute results.
  6. Inspect annotated screenshots: Compare your live results against the full-browser annotated reference screenshots provided in each lesson.
